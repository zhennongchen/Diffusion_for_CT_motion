# Diffusion-based generative model for Portable CT motion correction
**Author: Zhennong Chen, PhD**<br />

This is the GitHub repo based on a published paper: <br />
*Portable Head CT Motion Artifact Correction via Diffusion-based Generative Model* [link](https://www.sciencedirect.com/science/article/pii/S0895611124001551)<br />
Authors: Zhennong Chen, Siyeop Yoon, Quirin Strotzer, Rehab Naeem Khalid, Matthew Tivnan, Quanzheng Li, Rajiv Gupta, Dufan Wu<br />

**Citation**: Chen, Zhennong, et al. "Portable Head CT Motion Artifact Correction via Diffusion-based Generative Model." Computerized Medical Imaging and Graphics (2024): 102478.

## Description
We have proposed HeadMotion-Elucidated Diffusion Model(HM-EDM), to reduce the motion artifact in 3D portable brain CT scans.<br />
The main contributions of HM-EDM are as follows:<br />
(1) first diffusion-based generative model to tackle the motion artifact in CT, suppress performance aginst CNN-based methods.<br />
(2) utilize [Elucidated Diffusion Model framework](https://github.com/NVlabs/edm) for better performance and faster sampling. Introduce histogram equalization in the image pre-processing to balance the performance in brain tissue and skull. <br />
(3) trained on simulated CT scans (simulated motion on motion-free fixed CT images using portable CT scan geometry) and validated on real-world portable head CT scans.<br />
(4) note it can be used to corrected the motion artifact in conventional CT as well. 


## User Guideline
### Environment Setup
- You can build the docker from the folder ```docker```. <br />
- Step 1 needs ```/docker/docker_tensorflow``` and step 2-3 need ```/docker/docker_pytorch```

### Data Preparation (we have examples available!)
- **CT data**<br />
    - If you want to train the model, you need to simulate paired motion-free images (which are fixed CT scans you collected) and motion-corrupted images (which are generated by ```step1_motion_simulation.ipynb```) <br />
        - example data: motion-free image: ```example_data/data/fixed_CT```; simulated data: ```example_data/data/simulations```, where folder ```static``` is the motion-free ground truth, ```random_X``` are motion-corrupted images. <br />
    - If you want to apply the trained model on new cases, you only need motion-corrupted images: <br />
        - example data: real-world portable CT scan: ```example_data/data/portable_CT```. <br />
    - please pay attention to pixel size
        - to simulate data, we need [1,1,1]mm^3; while to input into model, we need [1,1,2.5]mm^3. check ```step1.ipynb``` to see how we resample the pixel sizes. <br />
    

- **Patient list** <br />
    - Please prepare a patient list following my format in ```example_data/data/Patient_list```. This is how my model enumerates the patient list <br />

- **Bins for histogram equalization** <br />
    - please run ```histogram_equalization.ipynb``` to generate the materials needed for histogram equalization data preprocessing.<br />
    - we have prepared the bins generated by our own dataset in ```example_data/histogram_equalization```, you can directly use it if needed.<br />

### Experiments
we have designed our study into 3 steps, with each step having its own jupyter notebook.<br /> 
**step1:  simulate paired data for model training**: use ```step1_motion_simulation.ipynb```.<br /> 

**step2: model training**: use ```step2_train.ipynb```.<br /> 

**step3: inference**: use ```step3_predict.ipynb```.   <br />
